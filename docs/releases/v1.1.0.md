首个公开版本：将佳能 HDR PQ HIF 照片批量转换为保留 HDR 高光和 EXIF 的 Ultra HDR JPG。

### 下载与运行

下载 **CanonHifHdr-Portable.zip**，完整解压后双击 **CanonHifHdr.exe**。这是完整的 Windows 10/11 x64 便携包，约 38 MB，无需安装 Python、无需管理员权限、无需联网。请保留同目录 `_internal` 文件夹。

`SHA256SUMS.txt` 提供 ZIP 的 SHA-256 校验值。

### 功能

- 中文 GUI，批量转换、质量设置、增益图缩放、进度和停止后续任务。
- 高位深 HIF 直接编码为带增益图的 Ultra HDR JPEG。
- 默认复制 EXIF：机身、镜头、时间、曝光、ISO、GPS（原片有时）和佳能 MakerNote。
- 同名文件自动编号，原片与已有输出不覆盖。
- 附带命令行入口、源码、构建脚本、依赖源码归档与许可证。

### 验证与限制

已通过 6 项自动测试；使用 5 张 Canon EOS R7 的 6960 × 4640、10 位 PQ / BT.2020 实拍 HIF 验证了 HDR/SDR 完整解码与 EXIF 一致性。最终便携包已在中文和空格路径解压、移除 Python 环境变量和 PATH 后完成启动及全部实拍转换。

JPEG 压缩为有损；显示 HDR 需要兼容的屏幕、系统设置和查看器。独立源 XMP 和 HEIF 专有容器字段不复制；过大或损坏的 EXIF 会报错。此版本未做数字签名，仅在 Windows 11 x64 上实际验证。
